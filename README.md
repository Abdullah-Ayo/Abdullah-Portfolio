# Lukman Abdullah — Data Analyst & Business Intelligence Portfolio

A modern, high-impact editorial portfolio website inspired by [Aurium Creative](https://auriumcreative.github.io/portfolioo/), crafted specifically for **Lukman Abdullah** to showcase enterprise Power BI dashboards, advanced SQL engineering pipelines, econometric modeling, and financial variance audits.

---

## ⚡ Highlights & Features

- **Infinite Top Marquee Ticker**: Smooth continuous scrolling banner highlighting core proficiencies (`POWER BI`, `SQL & CTES`, `EXCEL MODELING`, `DAX`, `ECONOMETRICS`).
- **Dynamic Hero & Terminal Reel**: High-contrast brutalist typography (`Anton` + `Space Grotesk`), rolling slot machine animation cycling through specializations, and portfolio year badge.
- **Interactive Slideshows & High-Res Lightbox**: Multi-slide project carousels with swipe/scroll support, dot indicators, and full-screen image expansion modal.
- **Challenge & Solution Case Study Structure**: Every dashboard breaks down the business challenge, data methodology, and quantifiable key findings.
- **Filter Tabs**: Instant client-side filtering between `All Projects`, `Power BI`, `Excel Modeling`, `SQL Engineering`, and `Econometrics`.
- **Fully Responsive & Zero External Dependencies**: 100% vanilla HTML5, CSS3, and modern JavaScript.

## 🚀 How to Deploy on GitHub Pages (Takes 2 Minutes)

### Option 1: Deploy on your existing `Abdullah-Portfolio` repo
1. Copy the files in this directory (`index.html`, `style.css`, `script.js`, and the `images/` folder) into your repository:
   ```bash
   # Inside your local Abdullah-Portfolio repository:
   git add .
   git commit -m "feat: launch new editorial portfolio design"
   git push origin main
   ```
2. On GitHub, go to your repository: **Settings** → **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In about 60 seconds, your site will be live at:
   👉 **`https://abdullah-ayo.github.io/Abdullah-Portfolio/`**

### Option 2: Deploy as your primary GitHub Profile site (`username.github.io`)
1. Create a new GitHub repository named exactly:
   **`Abdullah-Ayo.github.io`**
2. Upload these files (`index.html`, `style.css`, `script.js`, and `images/`).
3. Your portfolio will automatically be live at:
   👉 **`https://abdullah-ayo.github.io/`**
